Install Referrer 샘플 링크 생성기

구글 플레이 설치 링크의 referrer 값을 손쉽게 구성해 테스트할 수 있는 간단한 도구입니다.

생성된 referrer (원문) utm_source=play&utm_medium=cpc&utm_campaign=sample_campaign
URL 인코딩된 referrer
Play 스토어 설치 링크 설치 링크 열기

생성된 링크로 설치하면 앱 내 Install Referrer 조회 결과에 동일한 값이 표시됩니다.

디버그 설치나 APK 직접 설치에서는 Install Referrer 값이 제공되지 않습니다.
